# bluee - پروژه لاگر مقاومت زمین (نسخه پیشرفته V2)

این مخزن شامل مستندات، فریم‌ور و داده‌های اسکن برای **لاگر مقاومت زمین کاوشگر V2** است. نسخه ارتقا یافته با قابلیت‌های **هشدار اتصال کوتاه، تشخیص قطعی مدار، و پایش فرکانس (هدف ۱۳۷ هرتز)**.

## 📂 ساختار پوشه‌ها

- `docs/`: مستندات و طراحی PCB پیشرفته
  - `PDF EN.pdf`: مقاله انگلیسی اصلی (EPE، ۲۰۰۳)
  - `PDF FA.pdf`: راهنمای فارسی اصلی (گروه شکار در طبیعت)
  - `MANUALS_SUMMARY.md`: خلاصه و مقایسه
  - `COMPONENTS.md`: لیست قطعات اصلی
  - `PCB_PRO_DESIGN.md`: **طراحی PCB پیشرفته V2 و لیست قطعات ارتقا یافته**
- `firmware/`: کدهای مونتاژ
  - `EARTHRES411.ASM2.txt`: کد اصلی (جان بکر)
  - `EARTHRES_PRO_V2.ASM`: **کد پیشرفته (هشدار اتصال کوتاه، فرکانس ۱۳۷ هرتز، هشدار LCD)**
- `scans/`: داده‌ها و فایل‌های هگز
  - `kavoshgar scan.txt`: فایل هگز اصلی
  - `kavoshgar_pro_v2.hex`: **فایل هگز پیشرفته (با منطق هشدار)**
- `assets/`: تصاویر و نمودارها
  - `7748546 copy.jpg`: تصویر اسکن/نمودار

## 🛠️ قابلیت‌های نسخه پیشرفته V2
- **هشدار اتصال کوتاه (SHORT CIR!)**: تشخیص ولتاژ غیرطبیعی بین SK1 (زمین) و SK2/SK3/SK4.
- **پایش فرکانس (۱۳۷ هرتز)**:
  - **FREQ LOW**: فرکانس کمتر از ۱۳۰ هرتز.
  - **FREQ HIGH**: فرکانس بیشتر از ۱۴۵ هرتز.
- **تشخیص قطعی مدار (OPEN CIR!)**: فقدان سیگنال در گیرنده (RX).
- **نمایشگر LCD ۱×۱۱**: نمایش مستقیم هشدارها یا وضعیت "SCAN OK".
- **PCB کاوشگر_rs232 Pro**: مسیرهای مسی ضخیم‌تر، فیلترهای پاس‌باند ۱۳۷ هرتز، محافظت دیودهای زینر.
